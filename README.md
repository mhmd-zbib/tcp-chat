

### **Project Name:** TCP Chat System

#### **Main Purpose:**
A secure, multi-threaded TCP-based chat application featuring advanced cryptography and hardware-level security.

---

### **Repository Structure:**
The project is organized into the following key directories:

1. **`client/`**
   - Implementation of the TCP chat client.
   - Contains the source code, headers, and build configuration files related to the client application.

2. **`server/`**
   - Implementation of the TCP chat server.
   - Includes source code, headers, and build tools to manage server-side operations.

3. **`utils/`**
   - Houses shared utilities and logging mechanisms used by both the server and client applications.

4. **`docs/`**
   - Detailed documentation of the security features and architecture of this system.
   - Topics include hardware-level security, quantum-resistant cryptography, and implementation guides.

5. **`README.md`**
   - Provides an overview of the project's goals, features, and setup instructions.

---

### **Key Features/Technologies:**
- Multi-threaded architecture for concurrent client communication.
- Strong security practices with encryption and anti-debugging measures.
- Custom TCP-based messaging protocol that supports secure communication.
- Quantum-resistant cryptography and hardware-level random number generation.
- Cross-platform compatibility (optimized for Linux development).
